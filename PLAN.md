# nosleep - план

## Задача
Мак: при закрытой крышке сессия claude в терминале замирает (сон).
Нужно: работать при закрытой крышке + видеть, включён ли режим.

## Что есть
`nosleep.zsh` - функция для `~/.zshrc` (исходная версия, ещё не установлена).
Основа: `sudo pmset -a disablesleep 1/0` - единственное, что держит систему
без сна при закрытой крышке (`caffeinate` не помогает).
Режимы: `nosleep <cmd>` (флаг на время команды, снимается через trap),
`nosleep on|off|status`.

## Проблемы (исправить)
1. sudo в конце сессии снова спросит пароль (кэш ~5 мин), флаг повиснет.
   Решение: sudoers NOPASSWD только для `/usr/bin/pmset`
   (`sudo visudo -f /etc/sudoers.d/pmset`).
2. trap без HUP: закрытие вкладки терминала оставляет флаг включённым.
   Добавить HUP.
3. `status`: `grep -q SleepDisabled` ловит и значение 0.
   Нужно `grep -q 'SleepDisabled[[:space:]]*1'`.
   Проверить реальный вывод `pmset -g` на машине.
4. `kill -9` / краш не обработать - поэтому нужен индикатор.
5. Флаг переживает перезагрузку.
6. В строках скрипта em dash - заменить на дефис.

## Индикатор
- Вариант A: плагин SwiftBar (`brew install swiftbar`), файл вида
  `nosleep.5s.sh`, иконка ON/OFF, пункты меню on/off (нужен пункт 1, sudoers).
- Вариант B: метка "nosleep ON" в statusline Claude Code
  (репо claude-config, там есть statusline с группами расширений).
- Вариант не выбран - спросить.

## Порядок
1. Исправить функцию (пункты 2, 3, 6).
2. sudoers для pmset (пункт 1).
3. Установить в `~/.zshrc` (source из этого репо).
4. Индикатор (A и/или B).
5. Проверка: `nosleep claude`, закрыть крышку на несколько минут,
   открыть - сессия жива, после выхода `nosleep status` = OFF.
